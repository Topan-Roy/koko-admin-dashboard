# Koko Admin Dashboard

## What is this project?
The Koko Admin Dashboard is a React + TypeScript frontend application built with Vite. It serves as the central administrative interface for managing users, tracking financial transactions, viewing analytics, and overseeing platform activity for the Koko application.

## How to run the project

1. **Install dependencies**
Make sure you have Node.js installed, then install the necessary packages using your preferred package manager (npm, pnpm, or yarn):
```bash
npm install
```

2. **Run the development server**
Start the local Vite development server:
```bash
npm run dev
```

3. **Build for production**
When you're ready to deploy, create an optimized production build:
```bash
npm run build
```
